# Louie Mantia Hanafuda card artwork

The 48 PNG card faces in this directory are artwork by [Louie Mantia](https://louiemantia.com/), licensed under [Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/).

They were obtained, without modification, from the [`assets/cards` directory](https://github.com/game-prototypes/hanafuda/tree/main/assets/cards) of the `game-prototypes/hanafuda` project. That project identifies the original Wikimedia source on its [README](https://github.com/game-prototypes/hanafuda#readme).

The artwork remains available under CC BY-SA 4.0. The surrounding Bzunga application code is not derived from the source project's Godot code.
